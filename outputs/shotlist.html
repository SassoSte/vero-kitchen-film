Full directing style and production settings
Photorealistic architectural transformation. Realistic materials, believable weight and contact shadows; rigid appliances, plausible hands and tools. Locked source-based framing. No speech, music, captions or overlays. One readable physical action per source take; time jumps occur only in the edit. Never morph, teleport, dissolve, duplicate or pass objects through walls. Lead worker: short grey hair, navy work shirt, dark trousers, tan tool belt. Partner: grey shirt, dark trousers, dark cap, dark tool belt. Preserve worker identities from reviewed character references before submission.
Initial model plan: Kling 3.0 Omni Pro, silent 5-second source takes; quote and validate actual input settings before execution. Select Seedance only after a comparison demonstrates a benefit.
