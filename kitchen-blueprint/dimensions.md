## Method

1. Topology from the Entrata «Tallbot» render + 29-photo #2130 gallery + #2083 gallery
   (same plan, pre-reno kitchen photos).
2. Metric anchors: 30" range, 24" DW, 33" sink base, 25.5" counter depth incl. overhang,
   36" counter height — all visible in-frame, used as scale references.
3. Cross-check: bar length from 3 stools at 20–22" centers (photo-02); aisle from
   fridge-width ratio (photo-05/-26); run symmetry (both runs land within an inch of 10'3")
   — typical builder symmetry, taken as confirmation.
4. Whole-unit area reconciliation: kitchen zone ≈ 89–95 sqft ≈ 8.7% of 1,029 sqft —
   consistent with the render's proportion for the kitchen quadrant.
